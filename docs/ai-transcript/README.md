# AI coding transcript

The brief asks for the complete AI coding transcript when AI tools were used.
This project was built with Claude Code (Anthropic), and the commits it wrote
are marked with a `Co-Authored-By: Claude` trailer.

The session export belongs in this folder. It is added by hand, after a read
through, because a raw export can contain personal details from the author's
local setup that have nothing to do with the project.
